# Supporting Images

Store supporting screenshots and supporting images here.

Before publishing an image:

- Confirm it contains no credentials, tokens, account IDs, private IP addresses, customer data, personal data, or confidential or proprietary material.
- Crop unrelated interface content.
- Add useful alt text where the image is embedded.
- Use a descriptive lowercase kebab-case filename.
- Confirm that usage rights are clear.

Prefer diagrams or written instructions when a console screenshot would become outdated quickly.
