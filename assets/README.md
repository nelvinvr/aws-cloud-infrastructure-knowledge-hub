# Assets

Original visual assets supporting the knowledge hub.

## Structure

- [diagrams](diagrams/) — architecture and concept diagrams
- [images](images/) — screenshots and supporting images approved for public use

## Rules

- Prefer original diagrams.
- Do not upload confidential or proprietary visuals.
- Remove account IDs, credentials, private addresses, customer information, and other sensitive data.
- Use descriptive lowercase kebab-case filenames.
- Link each asset from the relevant article or lab.
- Record the source and permission for any third-party asset.
